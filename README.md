Esta práctica tiene como objetivo principal familiarizarme con el flujo de trabajo básico de Git y GitHub, incluyendo la gestión de ramas, la creación de Pull Requests (PR) y la resolución de conflictos.

Conceptos clave a explorar: Creación de ramas de características (feature), publicación remota de ramas, proceso de revisión (Pull Request), y manejo de conflictos de fusión.
